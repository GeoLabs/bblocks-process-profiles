# Attachment of the CWL processes to the tiers

Generated by `scripts/generate.py` from `tier3` in `scripts/profiles.yaml` (A4.1 of the tier
separation). Each of the 27 CWL processes of the OSPD reference workflows is compared with the
signatures of `bblocks-generic-profiles`: its inputs and outputs (as derived from its CWL) against the
roles of the candidate Implementation Profile (tier 3), of the Generic Profile it refines (tier 2) and
of that profile's Process Concept (tier 1). A process is attached (`implementsProfile`) only when
every role of the Implementation Profile is implemented by one of its inputs/outputs, possibly with
inputs/outputs of its own (Table 21 footnote b), and when the activity type of that profile means
what the process does. A process with no fitting profile is listed as not attached, with the reason
and, where one exists, the closest profile; it is not forced. A gap in the tiers may justify a new
Generic or Implementation Profile: listed as proposals, none created here.

The 31 live processes of the Geonovum testbed are all attached, one per Implementation Profile
(README, second table).

## Proposals (for GeoLabs to decide; nothing created)

- A Generic Profile for product selection (area of interest, time interval, collection, filters -> item references), implemented by algae-bloom.select-products-sentinel2 and kindgrove-steps.select-scene. (from `algae-bloom.select-products-sentinel2`, `kindgrove-steps.select-scene`)
- A Generic Profile for band retrieval (product reference, band name, optional area of interest -> raster), implemented by algae-bloom.download-band-sentinel2-stac-item, -product-safe, kindgrove-steps.download-band and water-bodies.crop. (from `algae-bloom.download-band-sentinel2-stac-item`, `algae-bloom.download-band-sentinel2-product-safe`, `water-bodies.crop`, `kindgrove-steps.download-band`)
- A Generic Profile for raster resampling (raster, target size or resolution -> raster). (from `algae-bloom.reproject-image`)
- A Generic Profile for raster rendering (raster, colour map -> image). (from `algae-bloom.plot-image`)
- A second Implementation Profile of the Generic Profile radiometric-index taking separate single-band rasters (no maxOccurs 1), for water-bodies.norm-diff and kindgrove-steps.calculate-indices. (from `water-bodies.norm-diff`, `kindgrove-steps.calculate-indices`)
- A Generic Profile for raster thresholding (raster -> single-band mask raster). (from `water-bodies.otsu`)
